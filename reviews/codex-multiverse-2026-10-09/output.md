**The multiverse is defensible, but it currently mixes alternative models, different estimands, and different target populations.** Those need separate reporting. Pre-specification constrains fitting choices; it doesn’t eliminate choices about emphasis afterward, contrary to the assurance in [analysis_plan.md:63](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:63).

1. **Dimensions: retain most, but fix some choices and add others.** The negative-binomial branch isn’t automatically defensible: independent counts contradict fixed response budgets and competition, already recognized in [H2 details:21](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:21). Retain it only with an explicit sampling rationale; conditioning independent Poisson counts on totals gives multinomial choice, whereas negative binomial introduces additional assumptions.

   Frequency held fixed versus integrated changes the estimand, not merely the specification ([69](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:69)). Word sets likewise change the population and competing vocabulary ([66](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:66)). Don’t combine these into one robustness tally.

   Missing dimensions: flexible versus linear valence adjustment; transport/measurement-invariance restrictions; outcome-to-rarity feedback versus restricted feedback; and substantively calibrated identifying priors, beyond merely “widened.” These follow directly from the identification limitations in [45–46](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:45). Freeze admissible combinations: unavailable indicators and unsupported scale bridges aren’t analytic alternatives. Lexical full factorials should include only relevant dimensions.

2. **Economy: replace one-at-a-time coverage with a targeted crossed design.** The proposal in [75](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:75) detects local sensitivity but can miss reversals from coupled assumptions. Indicators × vocabulary × availability is sensible, but also cross availability with valence-bias assumptions, and H1 controls with measurement reliability/feedback.

   Use D1b/D1c, before stereotype outcomes, to select a fixed fractional-factorial or space-filling design covering these interactions and plausible bias extremes. Predefine any additional crossing and its trigger. Compute both frequency estimands from the same posterior where possible; they needn’t require separate fits. Register convergence criteria, retry rules, and how failed fits remain visible. Report robustness only over the evaluated design.

3. **Reporting: avoid specification voting.** Report every estimate and interval in a fixed ordering, stratified by dataset, estimand, and target vocabulary, with a common contrast scale within each stratum. Standardizing prevalence separately within each subset changes what “1 SD” means; freeze the reference scaling where scientifically comparable.

   Apply the [H2 threshold rule:20](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:20) separately to every admissible specification. Predefine overall labels: *uniform meaningful support* if all qualify; *uniform evidence against that magnitude* if all qualify against; otherwise *specification-dependent*, showing inconclusive and conflicting branches. A share of supporting specifications is descriptive, not a posterior probability: duplicating grid points changes it. Report direction separately from magnitude. Don’t pool the separate confirmatory datasets into this tally ([17](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:17)).

4. **Model expansion: use it for measured uncertainty, not unidentified assumptions.** Gelman’s model-expansion preference (memory) fits respondent-level measurement, instrument-specific loadings, uncertain act-type coding, partially pooled affix effects, and regularized nonlinearities/interactions. The act-type proposal already follows this logic ([57](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:57)).

   Keep separate sensitivity fits for shared bias restrictions and feedback policies that observations cannot adjudicate. Bayesian averaging there can conceal identification assumptions inside prior weights. Different vocabularies and estimands also aren’t uncertain parameters of one scientific quantity.

5. **Rating study: it identifies a framing effect, not availability alone.** The claim in [77](/Users/brettreynolds/projects/LLM-CLI-projects/papers/development/marked-pole-stereotypes/analysis_plan.md:77) is too strong. Descriptions also change thresholds, specificity, extremity, and interpretation; neither framing establishes actual prevalence.

   Randomize framing within raters across different traits, but never show both versions of one trait to the same rater; counterbalance item–framing assignments and order. Fix population, timeframe, and response scale. Independently check semantic equivalence, thresholds, reading difficulty, and valence; include multiple validated descriptions per trait to estimate wording variation. Model rater and item effects plus item-specific framing slopes.

   Set completed ratings **per item per framing** through simulation targeting precision for framing differences and morphology/familiarity interactions. Budget and total participants alone don’t determine adequacy. To isolate availability more strongly, add a randomized accessibility manipulation using otherwise identical wording.
